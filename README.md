# 🏨 MauiAppHotel

Aplicativo mobile de reserva de quartos de hotel desenvolvido com **.NET MAUI** como projeto acadêmico.

## Funcionalidades

- Seleção de quarto ou suíte
- Definição da quantidade de adultos e crianças
- Escolha das datas de check-in e check-out
- Tela de resumo com o valor total da reserva calculado automaticamente

## Tecnologias

- .NET MAUI — C# — XAML

## Como executar

1. Abra a solução `MauiAppHote1.sln` no Visual Studio 2022
2. Selecione o dispositivo/emulador desejado
3. Pressione `F5`
